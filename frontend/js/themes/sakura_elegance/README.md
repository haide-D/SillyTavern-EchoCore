## 1. 核心世界观与美学体系

落樱雅境主题以日本平安时代公卿风雅与阴阳道美学（《源氏物语》/《阴阳师》平安雅道）为底蕴，跳脱传统的廉价高饱和粉色，开创了克制高级的**莫兰迪薄樱色盘**：

1. **色彩方案 (Morandi Sakura Palette)**：
   - **薄樱白 (`#FFF0F5`)**：如同晨曦初照在初绽花瓣上的微光，作为高光与文字主色；
   - **莫兰迪烟粉 (`#F4A6B8` / `#D48C9E`)**：克制、雅致、带有温润玉质感的灰调粉，作为核心光晕；
   - **哑光赤金 / 玫瑰金 (`#F5D0A9` / `#E5A696`)**：莳绘描金线与水引绳结，点缀贵族华美；
   - **暮夜绛紫半透毛玻璃 (`#1f141a`)**：深色模式基底，透光朦胧，极其护眼。

2. **悬浮入口：落樱折扇·晴明结界印 (Trigger / FAB)**：
   - **拒绝 2D 平面贴图**：采用 `perspective: 800px` 3D 空间倾角悬浮；
   - **双层反向自转结界天轨**：外圈顺时针 28s、中圈逆时针 22s 运转；
   - **工笔描金折扇**：扇面镂空微雕，三瓣樱花在扇面轻缓浮动；
   - **晴明五芒印流光**：扇心内嵌五芒星阵眼，灵力金芒沿星轨持续流转（`stroke-dasharray`）。

3. **Canvas 3D 落樱粒子物理系统 (`sakura_particles.js`)**：
   - 模拟真实樱花花瓣在空间中的 **3D 轴向翻转 (`scaleX/scaleY`)、微风扰动与重力下沉**；
   - 伴随晨曦微尘金粉与水引扩散微澜，点击悬浮球时触发漫天落樱爆发 (`burst()`)。

4. **主页场景：流光短册御牒 (Staggered Tanzaku Cards)**：
   - 彻底告别死板垂直列表与方块网格；
   - 模态框中央贯穿一条 **落樱灵力光轨 (Meridian Spine)**；
   - 各 App 以 **左右错落悬浮短册 (Tanzaku)** 呈现，每个节点内嵌 **琉璃樱纹方牌**；
   - **100% 纯矢量 SVG 图标**，严格杜绝 Emoji，实现跨平台一致高精渲染。

## 3. 核心设计铁律与避坑经验

1. **自由拖拽与持久化**：
   - 悬浮球松手后直接将 `top/left` 保存至 `localStorage`，**严禁使用动画强行向单侧吸附贴边**，保障用户停放自由度。
2. **主页场景点击路由**：
   - 统一调用 `ctx.engine.showScene(app.id)`，严禁臆造不存在的 `openApp` 或 `switchScene` 方法。
3. **通话/窃听 AudioPlayer 动态字幕绑定**：
   - 界面严禁使用静态占位字符串；
   - 必须向 `new AudioPlayer({ $container: $content, segments: callData.segments })` 传入容器与分段数据，由播放器驱动实时逐句高亮滚动渲染与「铭刻信笺/言灵」入酒馆聊天。
