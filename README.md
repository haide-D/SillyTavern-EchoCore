## ElevenLabs V3 与段落接力朗读

扩展设置中选择 **ElevenLabs · V3**，填写 API Key 与默认 Voice ID，保存后可同步账户音色或手动添加 Voice ID，再在角色绑定中选择 ElevenLabs 音色。表现力提供创意 / 自然 / 稳健三档；默认使用自然。后端管理页也可保存连接配置。升级代码后需要重启 EchoCore 后端并刷新酒馆页面。

使用 `eleven_v3` 的非流式接口。台词中的 Audio Tags 会原样送往模型，例如 `[Alice, whisper] “ [whispers] 别出声。[sighs] 我听见了。”`。外层标签用于识别角色，内层标签用于声音表现；标签请放在引号内，避免包含角色名或逗号。未写内层标签时，插件会把支持的外层情绪转为声音提示。可关闭高级 Audio Tags。标签实际表现取决于音色与模型，说明见 [ElevenLabs 官方指南](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)。

全文设置默认开启 **段落接力播放**：按自然段和句子分割，首段约 100 字符以内，之后约 240 字符以内（不切断音频标签）。第一段生成完整文件即可开播，播放时准备后两段；云端最多两个请求同时生成，本地模型仍串行切换。音频仍是逐段完整文件，不使用流式传输。多角色本地模型切换、网络与服务耗时仍可能造成段间等待。

旧设置选择过“批量准备”时，全文的段落接力优先；关闭段落接力可恢复原批量策略。完成后仍保存完整录音用于重播、拖动和下载。已有完整录音会直接复用，需要更换声音或表现力时使用“重新生成”。ElevenLabs 的缓存按音色、文本、标签和表现力区分；连接与同步音色不发起付费语音合成。

### 正文内声音控件与 BGM

每条 AI 消息正文上方提供全文朗读和 BGM 控件。主按钮开始 / 暂停朗读，桌面上的前后段按钮可跳到已准备的片段。完整录音保存后复用同一组控件，并显示可拖动进度；「更多」中保留对白连播、设置、下载和重新生成。匹配到正文原文时会高亮当前片段，不修改消息内容。

点击音乐名称展开选曲浮层，通过「导入音乐」添加本地音频（每个文件不超过 50 MB，格式需浏览器支持）。曲库保存在当前浏览器的 IndexedDB，不同浏览器 / 设备分别导入；清理站点数据会清除曲库。支持循环播放、暂停、切歌、移除和独立音量，各条消息共享一个音乐播放器。曲目和音量按聊天记忆，切换聊天停止旧音乐，刷新后由用户点击播放。新增控件只负责全文朗读与 BGM，原主题悬浮球及来电入口沿用已有实现。

## 📦 快速安装与使用指南

### 步骤 1: 安装插件到 SillyTavern
进入 SillyTavern 插件目录克隆本项目：
```bash
cd SillyTavern/data/default-user/extensions/
git clone -b V3.0.0 https://github.com/haide-D/SillyTavern-GPT-SoVITS.git SillyTavern-GPT-SoVITS
```

### 步骤 2: 启动插件后端服务
在 `SillyTavern-GPT-SoVITS` 目录下：
* **Windows**: 双击 `start.bat`
* **Linux / macOS**: 终端运行 `./start.sh`

### 步骤 3: 在管理面板配置模型
1. 浏览器打开 `http://localhost:3000/admin`
2. 配置 GPT-SoVITS 整合包安装路径，或在「模型管理」中创建角色并上传 `.pth` / `.ckpt` 与参考音频。
3. 在酒馆页面右下角点击悬浮球，即可畅享沉浸式语音与多场景交互！

### 🔄 如何轻松升级至 V3.0.0
* **方式 1（首推·最简单）**：访问管理面板 `http://localhost:3000/admin`，在仪表盘点击 **「⬇️ 立即更新」** 按钮；
* **方式 2**：在 SillyTavern 酒馆扩展设置中，找到本插件点击 **「Check for Updates / 检查更新」**；
* **方式 3（命令行）**：在插件目录下执行 `git pull origin main`，随后重启后端 `start.bat`。

## 全文朗读与连续读

AI 消息下方有两个独立入口，也可从「TTS 配置 → 全文朗读 / 连续读设置」配置：

- **全文朗读**：先在朗读设置选择旁白音色，并开启全文正文模板；后续回复使用 `<tts-body>…</tts-body>` 包裹完整正文。点击「全文朗读」核对提取预览，再开始播放人物与旁白。已绑定人物使用对应音色，未绑定人物使用旁白音色并在预览注明。关闭全文模板会恢复原有模板。
- **连续读**：按当前消息已有语音气泡的顺序接着播放，不增加旁白，不依赖全文模板。开启「新 AI 回复完成后自动读取现有对白气泡」，即可自动读新回复；不会自动播放历史消息。「自动生成语音」仍只负责提前合成。

两种朗读均支持暂停、继续和停止。切换聊天、编辑、删除、重生成或切换 swipe 会取消旧朗读；失败后停止，不自动重试。已经发出的合成请求可能继续完成，但停止后的返回结果不会自动播放。

**边生成边播放**：纯云端消息按正文顺序提交，最多同时合成 2 段；首段就绪即开播，播放时提前准备下一段，不用等全文生成完。旁白与人物使用同一套准备与播放流程，后面的语音提前完成也不会抢先播放。

**全文音频保存与重播**：全文片段全部生成后，自动按正文顺序合并为一个 WAV 文件，独立保存在后端 `data/fulltext_audio/`（不随普通片段缓存清理）。消息下方出现完整播放器，支持重播、拖动进度与下载；刷新页面后会恢复，重新点击「全文朗读」也优先播放已有成品，不重新合成。音频绑定聊天、消息位置、swipe 与正文内容，正文变化后不会串用旧音频。只有单独点击「重新生成」并确认才绕过内置供应商缓存重新合成，成功保存后替换旧成品。首次部署此功能需重启后端并刷新酒馆。

完整文件统一为 24kHz 单声道 WAV，单文件上限 200MB。保存需要后端连接与磁盘空间；保存失败会提示，旧成品保留。历史版本仅存于内存的片段需重新打开全文朗读，完成合并保存后才能跨刷新恢复。

「朗读设置 → 本地模型朗读方式」提供两种策略（含本地模型的混合消息也使用此选择）：

- **尽快开播**：按正文逐段生成，播放当前段时生成下一段；模型切换和合成保持串行，多角色交替可能增加切换次数。
- **批量准备**（本地默认）：尽量按同一模型集中生成，全部就绪后按正文顺序连播。

播放状态显示当前段数和已准备段数。停止会撤销尚未发出的朗读专属请求；普通「自动生成语音」的后台任务继续按其设置运行。云端与本地的合成可以同时进行，本地任务之间不会同时切换模型。

全文支持自定义正文起止标记及额外排除标签；默认排除思考、状态栏、选项、代码、脚本等。标记缺失、重复、嵌套或损坏时拒绝提取，避免误读非正文。旧消息需要符合正文标记与人物对白格式，才能使用全文朗读。设置保存在当前浏览器。

**这段开源旅程已经完成了它最美好的使命**：它为成千上万的酒馆玩家带来了沉浸的视听体验，也见证了我技术探索与架构成长的珍贵历程。

由于个人工作与生活重心调整，我将无法再把大量精力投入到社区的日常答疑和定制化功能维护中。**项目已全面开放微内核注册机制，未来的无限可能交由社区自由书写。**
