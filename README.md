# SillyTavern-GPT-SoVITS Middleware (ST-Direct-TTS)

[**English**](./README_EN.md) | [**简体中文**](./README.md)

![License](https://img.shields.io/badge/license-MIT-blue) ![Python](https://img.shields.io/badge/python-3.8+-yellow) ![SillyTavern](https://img.shields.io/badge/SillyTavern-Extension-purple) ![Version](https://img.shields.io/badge/version-v3.0.0-green)

这是一个为 **SillyTavern (酒馆)** 量身打造的 **GPT-SoVITS / 多 TTS 供应商** 深度全栈集成插件。

它不仅仅是一个简单的 TTS 连接器，它包含一个高性能 Python 后端管理器和一个现代化模块化前端扩展，提供了**创作者工坊 (Creative Workshop)**、**旗舰级高定主题系统**、**全链路非阻塞异步队列**、模型自动切换、智能音频缓存、以及多达 12 种气泡皮肤与全屏沉浸视听体验。

---

## 🚀 项目架构与分支说明 (Architecture & Branches)

本项目采用高度**模块化与可扩展**的全栈架构设计。

* **`V3.0.0` / `main` 分支**：🔥 **当前旗舰版本**。包含创作者工坊、巅峰主题系统、非阻塞异步队列、ElevenLabs V3 提示词注入、多供应商策略架构与反代支持。
* **`fe_RealTime` 分支**：🎙️ **实时流式语音对话系统 (Real-time Voice Chat)**。基于 WebSocket 实现了极低延迟的流式音频通信与 VAD (静音检测) 中断机制。
* **`fe_tg_bot` 分支**：🤖 **Telegram 智能机器人集成**。将核心引擎接入 Telegram Bot API，支持移动端远程调度。

### 1. 🎨 创作者工坊生态 (Creative Workshop)
* **纯 JSON 预设架构**：自由编排任意剧情场景，自由定义触发动机、情绪基调与提示词模板。
* **智能变量插槽**：支持一键插入 `{{speaker}}`、`{{user_name}}`、`{{context}}`、`{{lang_display}}`、`{{last_call_summary}}` 等动态变量。
* **AI 剧本生成设想**：输入一句话灵感，AI 自动为你生成结构化场景预设。
* **一键导入与导出**：一键导出为标准 `.json` 文件，方便在玩家社区与 Q 群中自由分享。

### 2. 🌌 巅峰视觉高定主题系统 (Theme Engine 2.0)
* **四大官方旗舰预置主题**：
  * ⚔️ **仙途凌霄 (`immortal_sword`)**：先天太极双鱼八卦盘悬浮球、天心剑脉中轴光轨、左右交错灵牒、青玉螺旋剑气与水墨流云 Canvas 粒子引擎。
  * 🌸 **落樱雅境 (`sakura_elegance`)**：3D 悬浮落樱折扇与晴明结界五芒星流光印、3D 翻转樱花花瓣物理引擎、和纸莳绘透光屏风。
  * ⚡ **夜之城·边缘行者 (`cyberpunk_edgerunners`)**：光刃字母 "V" 入口、全屏纯文本 0-SVG 军规黑客终端控制台（全键盘 `1~6` / `ESC` 交互）、荒坂绯红过载暴走、电弧火花与垂直数据流引擎。
  * 🪄 **死亡圣器 (`deathly_hallows`)**：冥想盆与魔杖施法沉浸式全屏交互。
* **规范化开发指南**：提供完善的 [主题开发标准文档](./frontend/js/themes/README.md)，包含完整生命周期钩子与标准 AI 提示词规范。

### 3. ⚡ 全链路非阻塞异步调度与多任务队列
* **待听多任务排队队列**：后台静默生成语音，支持多个来电与窃听任务排队，阅读前台丝滑流畅、彻底告别卡顿与显存溢出。
* **分段字幕动态高亮与铭刻**：播放器实时同步多角色分段字幕，支持一键将通话记录「📜 铭刻」写入 SillyTavern 主对话。

### 4. 🧠 深度提示词与活人感引擎
* **ElevenLabs V3 双 List 上下文锚定**：精准注入当前场景角色与情绪，大幅提升多角色对白合成一致性。
* **多轮对白与心理独白深度提取**：重构过滤解析器，精准分离剧情动作、心理独白与口头对白。
* **世界观词条自动抽取**：智能结合 World Info 设定，让 AI 对话剧情更具连贯性。

### 5. 🎛️ 现代化 Web Admin 控制台与反代支持
* **模块化管理面板**：访问 `http://localhost:3000/admin`，支持参考音频批量多选上传、批量删除、批量修改情绪前缀。
* **反向代理 HTTPS 支持 (Issue #2 修复)**：支持填写完整 `https://tts.xxx.com` 反代地址，自动升级 WebSocket 为 `wss://`，不追加 `:3000` 端口。
* **自定义服务端口**：支持在后台配置自定义 Manager API 端口。

## 📦 快速安装与使用指南

### 步骤 1: 安装插件到 SillyTavern
进入 SillyTavern 插件目录克隆本项目：
```bash
cd SillyTavern/data/default-user/extensions/
git clone -b V3.0.0 https://github.com/haide-D/SillyTavern-GPT-SoVITS.git st-direct-tts
```

### 步骤 2: 启动插件后端服务
在 `st-direct-tts` 目录下：
* **Windows**: 双击 `start.bat`
* **Linux / macOS**: 终端运行 `./start.sh`

### 步骤 3: 在管理面板配置模型
1. 浏览器打开 `http://localhost:3000/admin`
2. 配置 GPT-SoVITS 整合包安装路径，或在「模型管理」中创建角色并上传 `.pth` / `.ckpt` 与参考音频。
3. 在酒馆页面右下角点击悬浮球，即可畅享沉浸式语音与多场景交互！

### 🔄 如何轻松升级至 V3.0.0
* **方式 1（首推·最简单）**：访问管理面板 `http://localhost:3000/admin`，在仪表盘点击 **「⬇️ 立即更新」** 按钮；
* **方式 2**：在 SillyTavern 酒馆扩展设置中，找到本插件点击 **「Check for Updates / 检查更新」**；
* **方式 3（命令行）**：在插件目录下执行 `git pull origin main`，随后重启后端 `start.bat`。
