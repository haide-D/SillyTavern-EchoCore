🌟 V3.0 核心颠覆式改变（必读！）：
1. 【彻底告别手动配置预设词条！】
   以前：需要在酒馆预设里手动配置一堆复杂的词条和规则。
   现在：完全不用管预设！插件采用 ElevenLabs V3 标准格式 `[角色名, 情绪]`。
   只要你在管理面板给角色绑定了模型，插件就会【自动识别模型的所有情绪】，并在对话时【全自动将提示词精准注入给 AI】！AI 回复时会自动带上对应情绪，插件秒级合成对应语气的语音！

2. 【创作者工坊 (Creative Workshop)】
   支持自定义任意主动来电/私下窃听剧情场景！
   支持一键导入/导出社区群友分享的 `.json` 预设，更有 AI 一键帮你构思生成剧情剧本！

--------------------------------------------------------------------
【第一步：安装与后端启动】
--------------------------------------------------------------------
1. 安装插件到 SillyTavern：
   进入 SillyTavern → Extensions (扩展插件) → Install Extension (安装扩展)
   粘贴仓库地址：`https://github.com/haide-D/SillyTavern-GPT-SoVITS` 点击安装。
   （若是手机端连接电脑酒馆，直接按照手机远程连接模式输入电脑 IP 即可）。

2. 启动后端管理器 (超级重要！)：
   进入插件目录（通常为 `SillyTavern/data/default-user/extensions/st-direct-tts`）
   双击运行 `start.bat`（Windows）或 `./start.sh`（Linux/Mac）。
   此时会自动安装依赖并启动后端服务，黑窗请保持运行不要关闭。

3. 配置 GPT-SoVITS 推理核心：
   首次启动会自动在浏览器打开管理面板 `http://localhost:3000/admin`。
   - 在「仪表盘」中选择你的 GPU 类型（NVIDIA 通用版 / NVIDIA 50系版）；
   - 点击下方链接下载整合包并解压；
   - 将 GPT-SoVITS 解压后的根目录路径（包含 api_v2.py 的目录）粘贴到「GPT-SoVITS 安装路径」中；
   - 勾选「启动插件时自动启动 GPT-SoVITS API」，点击「保存配置」并点击「启动服务」。
   - 看到 GPT-SoVITS 状态变为绿色的【运行中】即代表配置完成！

--------------------------------------------------------------------
【第二步：角色模型与情绪音频绑定 (极简操作)】
--------------------------------------------------------------------
1. 在管理面板进入「🤖 模型管理」：
   - 点击「➕ 创建新模型」，输入角色名称（如：派蒙、芙宁娜、爱丽丝）；
   - 上传对应的 `.pth` 和 `.ckpt` 权重文件。

2. 在管理面板进入「🎵 音频管理」：
   - 选择刚刚创建的模型；
   - 点击「⬆️ 上传音频」（支持多选批量拖拽上传！）；
   - 设定好情绪标签（如：happy、sad、angry、gentle、default 等）与参考文本；
   - 💡 秘籍：上传好之后，【完全不需要在酒馆里做任何预设修改】！插件会自动读取这些情绪标签！

3. 回到酒馆对话：
   - 刷新酒馆页面（Ctrl + F5）；
   - 开启对话时，AI 会自动输出类似 `[芙宁娜, happy] 哈哈，这正是在下完美的演出！`；
   - 插件将自动精准识别 `happy` 情绪，调用对应的参考音频发出欢快生动的语音气泡！

--------------------------------------------------------------------
【第三步：创作者工坊 (Creative Workshop) 怎么玩？】
--------------------------------------------------------------------
1. 打开工坊：
   - 方式 A：点击酒馆界面右下角的悬浮小球，在弹出的手机界面中点击「🎨 创作者工坊」App；
   - 方式 B：直接在 Web 管理后台点击左侧的「创作者工坊」导航栏。

2. 导入社区优质预设：
   - 点击「📥 导入预设 (.json)」，选择群友或社区分享的预设文件，一键即可导入；
   - 支持分类筛选：全部 / 📞 主动来电 / 👂 私下窃听。

3. 构思与创建自己的场景预设：
   - 点击「✨ 新建场景预设」；
   - 可以手动编写预设名、角色动机与 Prompt（点击插槽按钮如 `{{speaker}}`、`{{user_name}}` 快速插入变量）；
   - 或者使用【AI 剧本生成设想】：输入一句话灵感（如：“深夜发现我还没睡，偷偷打电话来查岗的傲娇青梅竹马”），AI 自动为你一键生成全套结构化提示词！
   - 点击「💾 保存预设」后，在剧情发展到对应时机时，角色就会主动给你打电话或触发私密窃听！

4. 导出分享：
   - 在预设卡片上点击「📤 导出」，即可将你的作品生成标准 `.json` 文件分享到 Discord 社区！

【第五步：电话与窃听沉浸式交互】
--------------------------------------------------------------------
1. 接听与全屏沉浸通话：
   - 当角色来电时，悬浮球会触发对应主题的酷炫暴走动效与提示；
   - 点击悬浮球一键直达全屏沉浸通话界面，支持多角色分段字幕动态滚动高亮！
2. 铭刻聊天记录：
   - 通话结束后，点击通话界面的「📜 铭刻聊天」按钮，即可一键将该通电话的完整对白记录写入酒馆主聊天！
3. 重温历史记录：
   - 打开手机的通话/窃听 App，可以在历史列表中直接拖动进度条试听，或点击卡片一键重回全屏重温剧情！

--------------------------------------------------------------------
【常见问题与排错 (FAQ)】
--------------------------------------------------------------------
Q: 为什么右下角显示「⚠️ TTS断开」？
A: 说明后端 Python 服务未启动。请去插件目录双击运行 `start.bat`。

Q: 为什么生成的语音没有感情/一直是默认声音？
A: 检查音频管理中是否有上传带有情绪前缀的音频（如 `happy_xxx.wav`、`sad_xxx.wav`）。只要上传了对应情绪，AI 输出 `[角色名, 情绪]` 时就会自动匹配！

Q: 远程连接/反向代理怎么填？
A: 在酒馆原生扩展设置中开启远程连接，直接输入你的完整反代地址（如 `https://tts.xxx.com`）即可，系统会自动识别 HTTPS 并升级使用 WSS，不追加多余端口。
