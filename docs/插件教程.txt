1. 【彻底告别手动在酒馆预设里放词条！】
   以前：需要在酒馆预设中手工编写一堆复杂的正则、词条与规则，配置门槛极高。

   只要你在后台给角色绑定了模型，插件就会【全自动识别该模型拥有的全部情绪音频】，并在每轮对话前【全自动将精准情绪提示词动态注入给 AI】！AI 回复时会自动带上对应情绪标签，插件秒级合成对应语气的生动语音！

2. 【重磅！创作者工坊 (Creative Workshop) —— 小剧场自定义玩法全面爆发！】
   角色不再只是被动回复你，他们会根据剧情发展：
   - 📞 **主动给你打电话**（恋爱私语、查岗、紧急呼救、病娇突袭...）
   - 👂 **允许你私下偷听**（多角色背地密谈、修罗场密谋、情敌私聊...）
   更支持 **AI 一键生成剧本**、**智能变量插槽**、**一键导出/导入分享** 与 **一键将语音小剧场「铭刻」写入主聊天**！

【第一步：安装与后端服务启动】
--------------------------------------------------------------------
1. 安装插件到 SillyTavern：
   - 进入 SillyTavern → Extensions (扩展插件抽屉) → Install Extension (安装扩展)
   - 粘贴仓库地址：`https://github.com/haide-D/SillyTavern-GPT-SoVITS` 点击安装。
   （若是手机端连接电脑酒馆，直接按照手机远程连接模式输入电脑 IP 即可）。

2. 启动后端管理器 (超级重要！)：
   - 进入插件目录（通常为 `SillyTavern/data/default-user/extensions/SillyTavern-GPT-SoVITS`）
   - 双击运行 `start.bat`（Windows）或 `./start.sh`（Linux/Mac）；
   - 此时会自动安装依赖并启动后端服务，黑色控制台窗口请保持运行不要关闭。

3. 配置 GPT-SoVITS 推理核心：
   - 首次启动会自动在浏览器打开管理面板 `http://localhost:3000/admin`；
   - 在「仪表盘」中选择你的 GPU 类型（NVIDIA 通用版 / NVIDIA 50系版）；
   - 点击下方链接下载整合包并解压；
   - 将 GPT-SoVITS 解压后的根目录路径（包含 api_v2.py 的目录）粘贴到「GPT-SoVITS 安装路径」中；
   - 勾选「启动插件时自动启动 GPT-SoVITS API」，点击「保存配置」并点击「启动服务」；
   - 看到 GPT-SoVITS 状态变为绿色的【运行中】即代表配置完成！

--------------------------------------------------------------------
【第二步：角色模型与情绪音频绑定 (极简零配置)】
--------------------------------------------------------------------
1. 创建模型：
   - 在管理面板进入「🤖 模型管理」，点击「➕ 创建新模型」，输入角色名称（如：芙宁娜、爱丽丝、派蒙）；
   - 上传对应的 `.pth` 和 `.ckpt` 权重文件。

2. 上传情绪参考音频：
   - 在管理面板进入「🎵 音频管理」，选择刚刚创建的模型；
   - 点击「⬆️ 上传音频」（支持多选批量拖拽上传！）；
   - 设定好情绪标签（如：happy、sad、angry、gentle、shy 等）与参考文本；
   - 💡 **核心优势**：上传好之后，【完全不需要在酒馆里做任何预设修改】！插件全自动读取并接管！

3. 回到酒馆对话：
   - 刷新酒馆页面（Ctrl + F5）；
   - 开启对话时，AI 会全自动输出类似 `[芙宁娜, happy] 哈哈，这正是在下完美的演出！`；
   - 插件将自动精准识别 `happy` 情绪，调用对应的参考音频发出欢快生动的语音气泡！

--------------------------------------------------------------------
【第三步：🔥 创作者工坊 (Creative Workshop) 与小剧场自定义玩法深度指南】
--------------------------------------------------------------------
这是 V3.0 最强大的全新功能！你可以自由编排角色之间的所有私密互动与突发剧情。

1. 什么是小剧场玩法？
   - 📞 **【主动来电 (Phone Call)】**：
     当剧情到达关键时刻、或你一段时间没回消息、或角色情绪波动时，角色会主动向你发起全屏语音通话！
     例如：深夜查岗、害羞告白、紧急求助、病娇黑化质问。
   - 👂 **【私下窃听 / 密谋旁听 (Eavesdrop)】**：
     当场景中存在多个角色时，他们可能会背着你进行私密对话！
     你可以戴上“窃听器”旁听他们的多角色轮流对话，不同角色会自动调用各自绑定的专属语音模型！
     例如：两个情敌私下较劲、同伴背着你策划惊喜生日派对、反派密谋陷阱。

2. 如何进入创作者工坊？
   - 方式 A：点击酒馆界面右下角的悬浮小球，在弹出的手机界面中点击「🎨 创作者工坊」App；
   - 方式 B：直接在 Web 管理后台点击左侧的「创作者工坊」导航栏。

3. 零门槛！如何用 AI 一键生成你的专属小剧场剧本？
   - 点击「✨ 新建场景预设」；
   - 点击【AI 剧本生成助手】按钮；
   - 输入你的一句话剧情设想，例如：
     * “深夜发现我还在熬夜，傲娇的女友偷偷打电话过来查岗”
     * “两个平时不对付的女角色背着我商量明天约会该怎么打扮”
     * “病娇角色发现我和别人说话，打电话过来质问并要求见面”
   - AI 将在一秒内全自动生成：预设名称、场景分类、角色动机、适宜触发时机以及完整的系统提示词 (Prompt Template)！

4. 高阶定制：如何编写属于自己的小剧场 System Prompt？
   - 在提示词模板中，你可以点击插槽药丸一键插入动态变量：
     * `{{speaker}}`：当前发起通话/对话的角色名
     * `{{user_name}}`：玩家（你）的名字
     * `{{speakers_emotions}}`：该角色拥有的全部情绪列表（AI 会自动从中挑选情绪）
     * `{{context}}`：当前酒馆主聊天的最近对话上下文
     * `{{lang_display}}`：当前设定的目标语言
     * `{{last_call_summary}}`：上一通电话的简要摘要
     * `{{followup_call_instructions}}`：后续连环来电指导
   - 点击「💾 保存预设」后，小剧场即可在剧情推进时自然触发！

5. 社区交流与一键导入/导出分享：
   - 📤 **导出**：在工坊列表点击预设卡片上的「导出」按钮，即可生成单文件 `.json` 剧本预设；
   - 📥 **导入**：在工坊点击「📥 导入预设 (.json)」，选择群友或 Discord 社区分享的剧本文件，一秒导入即玩！
   - 欢迎把你的神仙剧本分享到 Discord 社区：`https://discord.gg/usSz6XPdK`！

6. 沉浸体验与「📜 铭刻聊天」无缝接驳：
   - 小剧场播放时，带有精确的时间轴分段字幕，多角色说话时当前字幕会实时滚动高亮！
   - 听完精彩的小剧场后，点击界面底部的「📜 铭刻聊天」按钮，即可一键将整段小剧场的语音与对白落盘写进酒馆主聊天记录中，让剧情无缝接轨！

【常见问题与排错 (FAQ)】
--------------------------------------------------------------------
Q: 为什么右下角显示「⚠️ TTS断开」？
A: 说明后端 Python 服务未启动。请去插件目录双击运行 `start.bat`。

Q: 为什么生成的语音没有感情/一直是默认声音？
A: 检查音频管理中是否有上传带有情绪前缀的音频（如 `happy_xxx.wav`、`sad_xxx.wav`）。只要上传了对应情绪，AI 输出 `[角色名, 情绪]` 时就会自动匹配！

Q: 远程连接/反向代理怎么填？
A: 在酒馆原生扩展设置中开启远程连接，直接输入你的完整反代地址（如 `https://tts.xxx.com`）即可，系统会自动识别 HTTPS 并升级使用 WSS，不追加多余端口。
